# התור

- [ ] רישיון למאגר: בעל החברה בוחר, והוא נכתב ב-`LICENSE` ובשני ה-README (הפריט הפתוח ב-`docs/state/distribution.md`).
- [ ] ניסוי בשיחה אינטראקטיבית שנפתחת ב"שמור" בלבד, בלי עריכת קובץ לפניה: האם הפקודות של השמירה עוצרות לבקש אישור (הפריט הפתוח ב-`docs/state/save.md`).
- [ ] הקמה בפרויקט עם התוסף שהותקן מגיטהאב, ובדיקה שהיא רצה בלי בקשות אישור. ההתקנה עצמה נבדקה ב-Windows במסלול הטרמינל (`claude plugin`). המסלול של פקודות `/plugin` לא נוסה מעולם, כי הן אינן קיימות בתוסף של VS Code.
- [ ] שימוש אמיתי בפרויקטים, הקמה ביד בכל פרויקט. מה שחוסם לשווא או חסר נרשם כפריט פתוח בתחום שלו, לפני שהתוסף ניתן לאנשים מחוץ לחברה.
